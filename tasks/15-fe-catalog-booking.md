# Экраны каталога и записи
- Каталог механиков: поиск, фильтр по услуге, пагинация — всё параметрами запроса к серверу. Карточки с изображением.
- Страница механика: изображение, описание, услуги; форма записи (услуга, дата и время, комментарий); список занятых интервалов на выбранную дату из /busy/; показывается расчётное время окончания.
- При 409 показать понятное сообщение из detail и обновить список занятости. Состояния загрузки, пустого списка и ошибки через StateView.
