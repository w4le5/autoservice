# API администратора
Только роль admin, префикс /api/admin/:
- CRUD mechanics/ (включая список услуг и image_url) и services/;
- users/ — список с поиском и пагинацией, PATCH role и is_active (себя заблокировать нельзя);
- events/?page= — журнал действий: кто, когда, какая бронь, from -> to.
Тесты: клиент и механик получают 403 на любой admin-эндпоинт; админ создаёт механика; смена роли пользователя.
